# 模型重力前馈（Pinocchio，RQ-025，默认关闭）

`trotbot_dynamics` 从 URDF 计算定基重力项并发布 `/model_tau_ff`，`motor_protocol_node` 按 `pinocchio_tau_ff_mode=replace|add` 合并进 MIT `tau_ff`。

```bash
ros2 launch trotbot trotbot_basic.launch.py \
  use_can_bridge:=true \
  use_pinocchio_tau_ff:=true \
  pinocchio_tau_ff_scale:=0.2

ros2 topic echo /model_tau_ff --once                             # name + effort（Nm，URDF 符号）
ros2 param set /motor_protocol_node pinocchio_tau_ff_mode off    # 一键关闭
```

- `pinocchio_tau_ff_scale` 建议从 0.2 起步，逐级 0.35 → 0.5；`tau_signs` 必须逐关节静力验证。
- 模型数据超过 `pinocchio_tau_ff_timeout_s`（默认 0.2s）未更新时，会自动回落到查表/总线偏置。
- 首次使用前需编译 `trotbot_dynamics`（依赖 `ros-humble-pinocchio`）。

换腿负载/加壳后可重标：

```bash
ros2 run trotbot_dynamics calibrate_gravity.py record --csv /tmp/gravity.csv
ros2 run trotbot_dynamics calibrate_gravity.py fit --csv /tmp/gravity.csv --write-yaml /tmp/rq025_calib.yaml
```

机身外壳/电路板/狗头不影响定基 `g(q)`；只有腿上的质量/质心变化需要重标。

参数表、符号验证步骤与 `sweep` 扫掠标定见 [`src/trotbot_can_bridge/README.md`](../../src/trotbot_can_bridge/README.md) 的「模型前馈：Pinocchio 重力补偿」一节。
